# D6-1: ScrapeKnowledge needs a DynamoDB grant, and the state machine should not wait on an empty scrape (from D6, knowledge scrape)

**Needs:** D5 (owner of `infra/cdk/lib/provisioning-stack.ts` and the state machine shape), D1 (saved basics).

## What D6 shipped (in owned files)
`services/provisioning/src/steps/scrape-knowledge.ts` is a Step Functions task. It reads the workflow state, fetches at
most 10 pages (5 s each, 2 MB total, robots.txt first), and writes `FACT#` items under `TENANT#<tenantId>` with
`verified: false`. It returns counts only (`pagesFetched, bytesRead, candidates, flagged, stored, skipped`), never page text.

Inputs it reads from the workflow state (nothing else):
- `onboardingId`, `tenantId` (set server-side by D1, as in D5-1)
- `basics.website` (D1 already puts `basics: { businessName, businessType, website? }` in the execution input)
- `basics.listings` (optional, up to 3 listing URLs; **nothing collects these yet**, so today only the website is read)

## Requested changes
1. **D5, `provisioning-stack.ts`** (needed for the step to work at all). Today the step is created with no setup:
   `invoke('ScrapeKnowledge', 'scrape-knowledge', '$.knowledge')`, so its role has no table access and every write fails.
   Give it the same item-level grant OrderNumber has, and nothing else:
   ```ts
   const knowledgeBranch = invoke('ScrapeKnowledge', 'scrape-knowledge', '$.knowledge',
     (fn) => allowItems(fn, ['dynamodb:PutItem'], tenantKeys))
     .next(waitOwner('AwaitFactsConfirmed', 'facts'));
   ```
   Do **not** grant it the Telnyx secret or any other secret, and keep it out of a VPC. The step fetches URLs the owner typed;
   it refuses private and metadata addresses, but the real protection against DNS rebinding is that there is nothing private
   or secret reachable from this function.
2. **D5, timeout.** The Lambda timeout is 60 s; the step stops starting requests at 45 s (`DEFAULT_LIMITS.deadlineMs`). If the
   timeout changes, tell D6 so the deadline moves with it. The default retry (2 attempts) is fine: writes are conditional,
   so a retry never duplicates or resets a fact.
3. **D5/D3, empty scrape.** If there is no website, the site disallows crawlers, or every page failed, the result has
   `stored: 0` and the step still succeeds. `AwaitFactsConfirmed` would then wait up to 3 days for an owner to confirm
   nothing. Suggest a Choice after ScrapeKnowledge: `$.knowledge.stored == 0` (and no existing facts) skips the wait. The
   onboarding agent then moves on with "I couldn't read much from your site, so tell me about parking, walk-ins and so on."
4. **D1 (optional, later).** To read listings (Google/Yelp/Facebook pages the owner names), `saveBasics` would keep
   `listings: string[]` (max 3, same public-URL check as `website`) and pass it through in `basics`. D6 already reads it.
