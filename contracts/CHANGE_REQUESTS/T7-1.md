# T7-1: let the root vitest config run `services/*/test-integration`

**From:** T7 (tool-api performance and DynamoDB). **Needs:** owner of `vitest.config.ts` (P3).

## Why
T7 owns `services/tool-api/test-integration/**`, but the root `vitest.config.ts` only includes `services/*/test/**`.
`make test` and `pnpm vitest run services/tool-api/` therefore never see them. They currently run only through
`pnpm vitest run --config services/tool-api/test-integration/vitest.config.ts`.

## Proposed change
In the root `vitest.config.ts` `include` list add `'services/*/test-integration/**/*.test.ts'`.
The DynamoDB Local file is `describe.skipIf(!process.env.DYNAMODB_LOCAL_ENDPOINT)`, so it reports as skipped when
no endpoint is configured; the other files in the folder are stub-based unit tests and need nothing.
If CI later starts DynamoDB Local (service container on port 8000), set `DYNAMODB_LOCAL_ENDPOINT=http://localhost:8000`
for the typescript job and those tests run for real.

Also extend `tsconfig.json` `include` with `services/*/test-integration/**/*.ts` and `services/*/bench/**/*.ts` so they are typechecked.
