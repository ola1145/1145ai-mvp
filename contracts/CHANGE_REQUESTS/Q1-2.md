# Q1-2: run the isolation self-tests under `make test`

**From:** Q1 · **To:** owner of the root `vitest.config.ts`

## What
Add `'tests/e2e/isolation/test/**/*.test.ts'` to `test.include` in `/vitest.config.ts`.

## Why
The self-test (`selftest.test.ts`, `env.test.ts`, `sigv4.test.ts`, `routes-drift.test.ts`) needs no network and no AWS,
and it is what proves the isolation assertions fail when isolation is broken. Today `make test` does not collect it.
The real-AWS file `isolation.e2e.test.ts` skips with a message when `ISOLATION_*` is unset, so it is safe to include.
