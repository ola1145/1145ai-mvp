# P8-1: tests/e2e/package.json (unowned file)

**From:** P8 (e2e harness) · **To:** P3 (dependency and lockfile steward) · **Contract change:** no

## What
`tests/e2e` is meant to be its own npm project (brief: "own lockfile, not in the pnpm workspace"), and both briefs run
`cd tests/e2e && npm test` (P8) and `cd tests/e2e && npm run isolation` (Q1). No issue owns `tests/e2e/package.json`,
so P8 cannot add it without failing the `ownership` check.

## Why it is safe to add right now
The P8 harness has zero dependencies. It uses `node:test`, `node:assert` and Node 22 built-in TypeScript type
stripping, and imports `packages/conversation-style/src/index.ts` by relative path. So there is no lockfile to
generate yet and `.github/workflows/e2e.yml` does not depend on this file (it runs `node --test` directly).
