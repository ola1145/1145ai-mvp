# E2-1: add `transcript.partial` to the event contract and route it to the live channel

**From:** E2 (call events) · **Needs:** contracts owner, `packages/shared` owner, realtime stack owner (P6)

## Why
`contracts/realtime/channels.md` lists `transcript.partial` (LiveKit engine only) on `/tenants/<tid>/live`, but:
- `contracts/events/events.schema.json` has no `transcript.partial` in the `type` enum and no `$defs` entry.
- `packages/shared/src/events.ts` `EventType` lacks it.
- `infra/cdk/lib/realtime-stack.ts` rule `ToLive` does not match `transcript.partial`.

The voice worker has `events:PutEvents` but cannot publish to AppSync Events directly (publish is IAM for the publisher
Lambda only), so `events.py` sends it through the bus like every other event.

## What E2 sends today
EventBridge `PutEvents`, `Source: 1145.voice`, `DetailType: transcript.partial`, standard envelope
(`correlationId` = call id), at most 2 per second per call, best effort (no retries):

```json
"transcript.partial": { "required": ["callId", "role", "text", "atSec"],
  "properties": { "callId": {"type": "string"}, "role": {"enum": ["agent", "caller"]},
                  "text": {"type": "string"}, "atSec": {"type": "number"} } }
```

## Asks
1. Add the enum value and `$defs` entry above to `events.schema.json`, and `'transcript.partial'` to `EventType`.
2. Add `'transcript.partial'` to the `ToLive` rule detail types (and keep other consumers, such as post-call, off it).

## Also for post-call (service owner)
The transcript object in S3 (`tenants/<tid>/transcripts/<callId>.json`) is
`{ "callId", "tenantId", "roomName", "turns": [{ "role": "agent"|"caller", "text", "atSec" }] }`.
`loadTranscript` should return `.turns`. The object is tagged `kind=transcript` for the 90-day lifecycle rule.

## Also for infra (voice-stack owner)
The task needs `TENANT_BUCKET` and `EVENT_BUS_NAME` (already set) and `s3:PutObject` plus `s3:PutObjectTagging` on
`tenants/*/transcripts/*` (`grantPut` already includes tagging).
